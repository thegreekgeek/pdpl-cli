
I'm thinking about how I want to represent and load data transformation files in whatever shape they end up being. I need a way to point to multiple files in some kind of flat file and then grab and run whatever files those represent. Some of the things I'd like to support:

- Pull from npm packages
- Pull from GitHub repos
- Pull from an arbitrary local source

I can focus on that last on but keep the others in mind. We're just pulling in the same type of imports from different places so the first two are just a matter of adding the way to get those files locally, something that might not actually make sense to do in this library.

What I'm thinking is to follow how Vite does it:

```ts
// get.config.mjs
import { Transformation1 } from '~/transform-file-1.js';
import { Transformation2 } from '~/transform-file-2.js';

export default {
  transforms: [ 
	  Transformation1(),
	  Transformation2() 
	]
}
```
