Brilliant! So easy to setup and use. I switched the DB process to use a file and I was able to navigate the data. I realized that my query was partitioning on the `id` from Strava but also using that ID for deleting, meaning that I just deleted all rows that had dupes. Switched that to the sequenced ID that is being created and it all worked great.

```sql
DELETE FROM 'strava'
WHERE _id IN (
	SELECT _id FROM (
		SELECT _id, ROW_NUMBER() OVER (PARTITION BY id) AS dupe_count FROM 'strava'
	) 
	WHERE dupe_count > 1
);
```
