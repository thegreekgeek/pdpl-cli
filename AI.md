# AI disclaimer

AI, specifically [Copilot](https://github.com/features/copilot), is currently being lightly used for the development of the code in this repo. Additions using AI are typically limited to 1-2 lines at a time and has only been in use for version 0.14.0 and beyond. All lines of code written by a human or an AI has been and will continue to be reviewed by a human before merging.
